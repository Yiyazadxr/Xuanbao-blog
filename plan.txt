     Context

     现有 D:\41211\Desktop\JiXun\Website 只有一个纯手写 HTML 导航栏骨架（完成度约 15%）。用户决定推倒重来，采用 Next.js 全栈架构全新设计一个现代化中文个人博客（站名「暄宝xr的博客」，栏目：首页/文章/社交/工具/关于作者）。

     UI 设计方向（渐进式动效策略）

     参考站点是 Awwwards 级 WebGL 创意站，一步到位不现实。采用三层渐进，架构上把首页 Hero 做成独立可替换组件（components/home/Hero.tsx）：

     1. 第一版（Phase 1）：深色沉浸首页 —— 超大字排版 Hero、CSS 渐变光斑/噪点背景、framer-motion 入场与滚动动画、鼠标跟随微交互。已能达到参考站"简约高级感"的大部分观感
     2. 第二版（Phase 7 视觉升级）：Lenis 平滑滚动 + Canvas 粒子场/shader 渐变背景（React Three Fiber + drei），页面过渡动画
     3. 远期：完整 3D 场景（R3F），仅替换 Hero 组件内部，不影响其余架构

     - 配色：深色底（近黑）+ 高对比白字 + 单一强调色（先用荧光青/紫做占位，全部走 globals.css CSS 变量，后续一处改全站变）；内页文章页支持亮/暗双主题（next-themes）
     - 字体：中文无衬线（系统字体栈优先，避免大字体文件），标题超大字重对比

     数据写操作优先用 Server Actions（少写 API 路由，对初学者更直观）；只有确需对外暴露的接口才建 app/api/。

     数据模型（prisma/schema.prisma）

     - User：id、name、email(unique)、password(bcrypt 哈希)、image、role(READER|ADMIN)
     - Post：title、slug(unique)、content(Markdown)、excerpt、coverImage、published、featured、viewCount、authorId→User、categoryId→Category
     - Category：name、slug、description ←1:N→ Post
     - Tag ←N:N→ Post（中间表 PostTag）
     - Comment：content、postId→Post、authorId→User、parentId 自引用（嵌套回复）、isApproved(默认 false，审核制)
     - Like：userId + postId（联合唯一，登录用户一文一赞）
     - AccountRequest：email、message、status(PENDING|APPROVED|REJECTED)、createdAt —— 访客的账号申请
     - InviteCode：code(unique)、email(可绑定指定邮箱)、usedById→User?、expiresAt —— 博主分配的邀请码

     注册/登录流程（邀请码制）

     1. 访客在 /register 提交邮箱 + 申请说明 → 写入 AccountRequest + lib/mail.ts 发邮件到博主 QQ 邮箱（ADMIN_EMAIL）
     2. 博主登录后台 /admin/invites：查看申请 → 生成邀请码（可绑定申请者邮箱）→ 发给申请者
     3. 申请者回到 /register 填写 邀请码 + 邮箱 + 密码 → 校验邀请码有效且未使用（若绑定了邮箱须一致）→ 创建 User、标记邀请码已用
     4. /login 邮箱密码登录（Auth.js Credentials + JWT session）
     5. 种子脚本直接创建博主的 ADMIN 账号（不走邀请码）

     备注

     - SQLite 不能跑在 Vercel Serverless 上；未来部署时把 Prisma datasource 换成 Neon Postgres + 迁移即可，代码层零改动
     - QQ 邮箱 SMTP 需要在 QQ 邮箱设置中开启 SMTP 服务并获取授权码（不是 QQ 密码），填入 .env 的 SMTP_PASS
     - 主色调所有取色集中在 globals.css 的 CSS 变量，用户想好配色后一处修改全站生效
     - @uiw/react-md-editor 是客户端组件，需用 next/dynamic + ssr: false 引入，并适配暗色主题（data-color-mode）
